# Package index

## Create and save dynamic spectrograms

Start a dynamic spectrogram of a sound (or of a video) or a comparison
of sounds, add layers with `+`, and save it as a web page, video or
image.

- [`dynaspec()`](https://marce10.github.io/dynaSpec/reference/dynaspec.md)
  : Create dynamic spectrograms
- [`ds_compare()`](https://marce10.github.io/dynaSpec/reference/ds_compare.md)
  : Compare sounds with dynamic spectrograms
- [`save_dynaspec()`](https://marce10.github.io/dynaSpec/reference/save_dynaspec.md)
  : Save dynamic spectrograms
- [`` `+`( ``*`<dynaspec>`*`)`](https://marce10.github.io/dynaSpec/reference/plus-.dynaspec.md)
  : Add layers to dynamic spectrograms

## Panels

The parts of the figure, added as layers (only the panels added are
shown).

- [`ds_spectrogram()`](https://marce10.github.io/dynaSpec/reference/ds_spectrogram.md)
  : Spectrogram layer of dynamic spectrograms
- [`ds_oscillogram()`](https://marce10.github.io/dynaSpec/reference/ds_oscillogram.md)
  : Oscillogram layer of dynamic spectrograms
- [`ds_envelope()`](https://marce10.github.io/dynaSpec/reference/ds_envelope.md)
  : Amplitude envelope layer of dynamic spectrograms
- [`ds_spectrum()`](https://marce10.github.io/dynaSpec/reference/ds_spectrum.md)
  : Power spectrum layer of dynamic spectrograms
- [`ds_overview()`](https://marce10.github.io/dynaSpec/reference/ds_overview.md)
  : Overview layer of scrolling spectrograms
- [`ds_video()`](https://marce10.github.io/dynaSpec/reference/ds_video.md)
  : Video layer of dynamic spectrograms

## Filter the sound

Changes the sound itself (what is shown and heard).

- [`ds_filter()`](https://marce10.github.io/dynaSpec/reference/ds_filter.md)
  : Frequency filter layer of dynamic spectrograms

- [`ds_annotations()`](https://marce10.github.io/dynaSpec/reference/ds_annotations.md)
  : Annotation layer of dynamic spectrograms
- [`ds_captions()`](https://marce10.github.io/dynaSpec/reference/ds_captions.md)
  : Caption layer of dynamic spectrograms

## Styles

## Player

- [`ds_player()`](https://marce10.github.io/dynaSpec/reference/ds_player.md)
  : Player settings of dynamic spectrogram web pages
